# اسپیدچکر (SpeedChecker) — تست سرعت اینترنت و VPN

**[English](README.md)** · پایتون **۳.۱۰+** · PyQt6 · لایسنس MIT

برنامه دسکتاپ مدرن (PyQt6 با تم تیره و پشتیبانی **فارسی/انگلیسی** با چیدمان راست‌به‌چپ) به‌همراه CLI برای سنجش سرعت اینترنت — مستقیم روی سرورهای Speedtest.net یا از مسیر لوکیشن‌های ExpressVPN — با کیلومترشمار زنده، نمودار زنده، تاریخچه و لاگ زنده.

## شروع سریع — بدون نصب پروژه

```bash
git clone https://github.com/humorheatyt/speedchecker.git
cd speedchecker
python -m venv .venv
source .venv/bin/activate          # ویندوز: .venv\Scripts\Activate.ps1
pip install -r requirements.txt    # فقط PyQt6 نصب می‌شود؛ خود پروژه به‌صورت ماژول نصب نمی‌شود
python app.py                      # رابط گرافیکی
python app.py --cli --demo -s -r 3 locations.json   # خط فرمان (دموی آفلاین)
```

## نیازی به نصب speedtest نیست

اسپیدچکر یک **موتور تست سرعت داخلی با پایتون خالص** دارد (`src/speedchecker/engine.py`): پینگ و دانلود/آپلود چنداتصاله روی سرورهای معمولی Speedtest.net، با نمایش سرعت لحظه‌ای هنگام انتقال داده. حالت **خودکار ابتدا از همین موتور زنده استفاده می‌کند** و اگر لازم باشد به باینری Ookla برمی‌گردد. Ookla پینگ و سرعت‌ها را فقط پس از پایان تست تحویل می‌دهد؛ برای کیلومترشمار زنده از حالت خودکار/داخلی استفاده کنید. باینری اختیاری Ookla را می‌توان پس از پذیرش لایسنس/GDPR در `vendor/` دانلود کرد؛ نصب سیستمی انجام نمی‌شود. روش دستی و پلتفرم‌های دیگر در `vendor/README.md` آمده است.

## امکانات رابط گرافیکی

- **خانه** — دو کیلومترشمار جدا برای دانلود و آپلود، سرعت و نمودار زنده، پینگ اندازه‌گیری‌شده (ms) و سرور تست، شروع/توقف. مقیاس کیلومترشمار با واحد انتخابی (از جمله MB/s) سازگار می‌شود.
- **لوکیشن‌ها** — دریافت تمام regionهای گزارش‌شده توسط `expressvpnctl get regions` (نه سرورهای Ookla)؛ انتخاب چندگانه با Ctrl، و با انتخاب یک گروه (مثلاً یک کشور) همهٔ اندپوینت‌های داخل آن هم انتخاب می‌شوند (Ctrl+کلیک روی گروه همه را با هم روشن/خاموش می‌کند). تست‌ها دقیقاً به همان ترتیب انتخاب اجرا می‌شوند و انتخاب با تغییر ترتیب/دسته‌بندی یا جستجو از بین نمی‌رود. تست دسته‌ای اگر چیزی انتخاب شده باشد همان انتخاب را اجرا می‌کند و در غیر این صورت همهٔ لوکیشن‌های نمایش‌داده‌شده را. سرعت از طریق سرور جداگانهٔ Ookla سنجیده می‌شود و region فقط برای اتصال VPN استفاده می‌شود. برای اجرای واقعی، کلاینت ExpressVPN فعال و `expressvpnctl` در PATH لازم است.
- **تنظیمات** — زبان فارسی/انگلیسی، واحد سرعت (Mbps، Gbps، Kbps، bps، MB/s، GB/s، KB/s، MiB/s، KiB/s)، تعداد تکرار هر تست، **تایم‌اوت اتصال/دستور/هر تست**، مدت هر فاز، تعداد اتصال موازی، موتور تست (خودکار/داخلی/Ookla/دمو)، پذیرش لایسنس Ookla، اتصال ExpressVPN (پیش‌فرض روشن)، تست مستقیم یک‌باره پیش از VPN و اجازهٔ صریح برای قطع اتصال موجود. حالت خودکار ابتدا از موتور داخلیِ زنده استفاده می‌کند و در صورت خطا به Ookla برمی‌گردد؛ گزینهٔ Ookla ابتدا آن را امتحان می‌کند و در صورت خطا موتور داخلی جایگزین می‌شود. دانلود باینری Ookla انتخاب موتور را تغییر نمی‌دهد.
- **تاریخچه** — همهٔ تست‌ها (موفق و خطادار) در `~/.speedchecker/history.json` ذخیره می‌شوند؛ پینگ (ms) در صفحهٔ خانه، لاگ و جدول تاریخچه نمایش داده می‌شود و در صورت شکست دانلود/آپلود هم نگه داشته می‌شود. فیلتر وضعیت، متن، حداقل دانلود یا حداکثر پینگ؛ خروجی گرفتن و پاک‌کردن.
- **لاگ زنده** — هر چیزی که اجرا یا دریافت می‌شود همان لحظه نمایش داده می‌شود و قابل ذخیره است.

**حالت دمو** به‌صورت آفلاین سرورها و اندازه‌گیری‌ها را شبیه‌سازی می‌کند.

## خط فرمان (CLI)

```bash
python app.py --cli locations.json                 # خودکار: ابتدا موتور داخلی، سپس Ookla
python app.py --cli --engine ookla locations.json  # باینری Ookla از vendor یا PATH
python app.py --cli --demo -s -r 3 locations.json  # شبیه‌سازی آفلاین
```

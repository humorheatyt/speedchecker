# اسپیدچکر (SpeedChecker) — تست سرعت اینترنت و VPN

**[English](README.md)** · پایتون **۳.۱۰+** · PyQt6 · لایسنس MIT

برنامه دسکتاپ مدرن (PyQt6 با تم تیره و پشتیبانی **فارسی/انگلیسی** با چیدمان راست‌به‌چپ) به‌همراه CLI برای سنجش سرعت اینترنت — مستقیم روی سرورهای Speedtest.net یا از مسیر لوکیشن‌های ExpressVPN — با کیلومترشمار زنده، نمودار زنده، تاریخچه و لاگ زنده.

## شروع سریع — بدون نصب پروژه

```bash
git clone https://github.com/humorheatyt/speedchecker.git
cd speedchecker
python -m venv .venv
source .venv/bin/activate          # ویندوز: .venv\Scripts\Activate.ps1
pip install -r requirements.txt    # فقط PyQt6 نصب می‌شود؛ خود پروژه به‌صورت ماژول نصب نمی‌شود
python app.py                      # رابط گرافیکی
python app.py --cli --demo -s -r 3 locations.json   # خط فرمان (دموی آفلاین)
```

## نیازی به نصب speedtest نیست

اسپیدچکر یک **موتور تست سرعت داخلی با پایتون خالص** دارد (`src/speedchecker/engine.py`): پینگ، دانلود و آپلود چنداتصاله روی سرورهای معمولی Speedtest.net با نمایش سرعت لحظه‌ای. اگر باینری رسمی Ookla را ترجیح می‌دهید، کافی است آن را داخل پوشه `vendor/` بگذارید (راهنما: `vendor/README.md`) تا خودکار استفاده شود — بدون نصب سیستمی.

## امکانات رابط گرافیکی

- **خانه** — دو کیلومترشمار جدا برای دانلود و آپلود، سرعت لحظه‌ای زنده، نمودار زنده، نمایش پینگ و سرور، شروع/توقف.
- **سرورها** — دریافت **لیست کامل سرورهای Speedtest.net** و دسته‌بندی مثل ExpressVPN (بر اساس کشور/اسپانسر/حرف اول) و مرتب‌سازی بر اساس نام، کشور، شهر، اسپانسر، اندپوینت (هاست)، فاصله، پینگ، ترتیب فایل یا تصادفی. جستجو هم دارد. امکان بارگذاری لیست از فایل JSON (از جمله فرمت `locations.json`)، تست **هر سرور دلخواه** (دابل‌کلیک)، تست یک گروه، یا **تست دسته‌ای کل لیست به‌ترتیب**.
- **تنظیمات** — زبان فارسی/انگلیسی، واحد سرعت (Mbps، Gbps، Kbps، bps، MB/s، GB/s، KB/s، MiB/s، KiB/s)، تعداد تکرار هر تست، **تایم‌اوت اتصال/دستور/هر تست**، مدت هر فاز، تعداد اتصال موازی، اجرای سریالی، انتخاب موتور (خودکار/داخلی/Ookla/دمو)، پذیرش لایسنس Ookla و اتصال اختیاری با ExpressVPN قبل از هر تست.
- **تاریخچه** — همه تست‌ها و اتصال‌ها (موفق و خطادار) در `~/.speedchecker/history.json` ذخیره می‌شوند؛ فیلتر بر اساس وضعیت (فقط خطاها/فقط موفق‌ها)، متن، حداقل دانلود یا حداکثر پینگ؛ خروجی گرفتن و پاک‌کردن.
- **لاگ زنده** — هر چیزی که اجرا یا دریافت می‌شود همان لحظه نمایش داده می‌شود و قابل ذخیره است.

**حالت دمو** به‌صورت آفلاین سرورها و اندازه‌گیری‌ها را شبیه‌سازی می‌کند.

## خط فرمان (CLI)

```bash
python app.py --cli locations.json                 # اجرای واقعی (موتور داخلی)
python app.py --cli --engine ookla locations.json  # باینری Ookla از vendor یا PATH
python app.py --cli --demo -s -r 3 locations.json  # شبیه‌سازی آفلاین
```

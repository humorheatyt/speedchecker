# vpnchecker — نسخهٔ پایتونی تست سرعت ExpressVPN

بازنویسی پروژهٔ [toriqo/expressvpnspeedtest](https://github.com/toriqo/expressvpnspeedtest)
با **پایتون ۳٫۱۰ یا بالاتر**. هیچ کد، کامپایلر یا وابستگی Go لازم نیست و برنامه در زمان
اجرا وابستگی پایتونیِ جانبی ندارد.

> این برنامه سرویس VPN نیست؛ برای تست واقعی، درست مثل پروژهٔ اصلی، به اشتراک فعال
> ExpressVPN، ابزار `expressvpnctl` و ابزار رسمی Ookla به نام `speedtest` نیاز دارد.
> بستهٔ پایتونی `speedtest-cli` جایگزین سازگاری برای ابزار رسمی نیست.

## امکانات

- سنجش سرعت پایه بدون ExpressVPN؛
- اتصال خودکار به موقعیت‌های داخل فایل JSON، یکی پس از دیگری؛
- تست‌های ترتیبی یا موازی با تعداد قابل تنظیم؛
- میانگین دقیق دانلود، آپلود و تأخیر و ثبت زمان اتصال؛
- خروجی JSON سازگار با فیلدهای اصلی، همراه با نمونه‌ها و جزئیات خطا؛
- محدودیت زمانی برای فرمان‌ها و انتظار اتصال؛
- قطع اتصال پس از هر موقعیت، حتی در صورت خطای اتصال یا تست؛
- ذخیرهٔ مرحله‌ای و اتمیک، بدون بازنویسی گزارش قبلی؛
- حالت آزمایشی آفلاین، تست‌های خودکار و CI گیت‌هاب.

## نصب و اجرای آزمایشی

```bash
git clone https://github.com/humorheatyt/vpnchecker.git
cd vpnchecker
# تا پیش از ادغام PR، نسخهٔ پایتونی در این شاخه قرار دارد:
git checkout arena/7b469e38-vpnchecker
python3 -m venv .venv
source .venv/bin/activate
python -m pip install .

vpnchecker --demo -s -r 3 locations.json
```

در PowerShell ویندوز، محیط مجازی را با `.venv\Scripts\Activate.ps1` فعال کنید.
فرمان‌های `python -m vpnchecker` و `expressvpnspeedtest` هم قابل استفاده‌اند.

حالت `--demo` هیچ اتصال شبکه یا VPN را تغییر نمی‌دهد. اعداد آن **ساختگی** هستند و
گزارش با `"Demo": true` مشخص می‌شود؛ این حالت برای بررسی نصب و عملکرد برنامه است.

## اجرای واقعی

ابتدا ابزارهای رسمی را نصب و ExpressVPN را فعال کنید. برای بررسی سازگاری کلاینت:

```bash
expressvpnctl get regions
expressvpnctl get connectionstate
speedtest --version
```

این پروژه رابط `expressvpnctl` را هدف می‌گیرد، نه فرمان قدیمی `expressvpn`.
پشتیبانی عملی هر سیستم‌عامل به وجود همین رابط در نسخهٔ نصب‌شدهٔ کلاینت وابسته است.

فایل `locations.json` را متناسب با شناسه‌های موجود در `get regions` ویرایش کنید:

```json
{
  "locations": [
    {"country": "Netherlands", "city": "Amsterdam"},
    {"country": "Canada", "city": "Toronto"},
    {"country": "USA", "city": "New York", "region": "usa-new-york"}
  ]
}
```

`country` الزامی است. `city` و `region` اختیاری‌اند. شناسهٔ دقیق شهر بر شناسهٔ کشور
اولویت دارد. فاصله و زیرخط به خط تیره تبدیل می‌شوند و بزرگی/کوچکی حروف مهم نیست.
اگر `region` بدهید، همان شناسه باید وجود داشته باشد. موقعیت‌های نمونه تضمین نمی‌کنند
که سرورهای فعلی کلاینت شما همین نام‌ها را داشته باشند.

```bash
# سه تست ترتیبی برای سرعت پایه و هر موقعیت
vpnchecker -s -r 3 locations.json

# پنج تست موازی برای سرعت پایه و هر موقعیت
vpnchecker locations.json

# پذیرش صریح شرایط Ookla و انتخاب مسیر گزارش جدید
vpnchecker -s -r 3 --accept-license -o results-my-run.json locations.json

# راهنمای کامل
vpnchecker --help
```

قبل از تست واقعی، شرایط Ookla را با اجرای تعاملی `speedtest` بررسی کنید؛ یا در صورت
پذیرش شرایط مجوز و GDPR، گزینهٔ `--accept-license` را بدهید. برنامه خودسرانه آن‌ها را
نمی‌پذیرد.

## نکات مهم شبکه و حریم خصوصی

- تست سرعت ممکن است حجم زیادی از اینترنت مصرف کند. تست‌های موازی برای پهنای باند
  مشترک رقابت می‌کنند؛ خروجی، **میانگین** آن‌هاست نه مجموعشان. برای مقایسه، حالت
  ترتیبی `-s` معمولاً قابل‌تفسیرتر است. حداکثر ۳۲ تست هم‌زمان اجرا می‌شود.
- تست پایه عمداً بدون ExpressVPN انجام می‌شود. اگر به حفاظت مداوم VPN نیاز دارید،
  این برنامه را اجرا نکنید. VPNهای دیگر و پراکسی‌ها تشخیص داده نمی‌شوند.
- اتصال موجود بدون اجازه قطع نمی‌شود؛ ابتدا خودتان قطع کنید یا آگاهانه گزینهٔ
  `--disconnect-existing` را بدهید. **اتصال اولیه پس از تست بازیابی نمی‌شود.**
- پس از هر تلاش اتصال، قطع اتصال انجام می‌شود. اگر قطع اتصال شکست بخورد، اجرای
  موقعیت‌های بعدی متوقف خواهد شد؛ وضعیت VPN را دستی بررسی کنید.
- Ctrl+C و SIGTERM باعث تلاش برای پاک‌سازی اتصال و ذخیرهٔ نتایج دسته‌های تکمیل‌شده
  می‌شوند. تست‌های موازیِ در حال اجرا ممکن است تا پایان مهلتشان ادامه پیدا کنند.
  قطع برق، SIGKILL یا وقفه‌های تکراری تضمینی برای قطع VPN باقی نمی‌گذارند.
- Network Lock یا اتصال مجدد خودکار ممکن است تست پایه را ناموفق کند؛ برنامه تنظیمات
  امنیتی کلاینت را غیرفعال نمی‌کند.
- گزارش شامل نام دستگاه، سیستم‌عامل و موقعیت‌های تست‌شده است؛ پیش از انتشار آن را
  بررسی کنید. فایل‌های `results-*.json` عمداً وارد گیت نمی‌شوند.

## گزارش و گزینه‌ها

گزارش به‌صورت پیش‌فرض در `results-<timestamp>.json` ذخیره می‌شود. مسیر دلخواه را با
`-o` تعیین کنید؛ فایل موجود بازنویسی نمی‌شود.

فیلدهای اصلی `MachineName`، `OS`، `WithoutVPN` و `VPNStats` حفظ شده‌اند. نسخهٔ جدید
`Baseline`، نمونه‌های هر تست، شمارش موفق/ناموفق، `Errors` و `Status` را نیز دارد.
پهنای باند Ookla از بایت‌برثانیه با تقسیم بر ۱۲۵۰۰۰ به Mbps تبدیل می‌شود. میانگین‌ها
قبل از قالب‌بندی گرد نمی‌شوند و تأخیر نیز میانگین گرفته می‌شود. موقعیت VPN با موقعیت
سرور Speedtest اشتباه گرفته نمی‌شود. زمان‌ها UTC هستند.

| گزینه | کاربرد |
| --- | --- |
| `-s` / `--serial` | اجرای ترتیبی |
| `-r N` / `--repeat N` | تعداد تست هر مرحله، پیش‌فرض ۵ |
| `-o PATH` / `--output PATH` | مسیر گزارش جدید |
| `--command-timeout SEC` | مهلت هر فرمان VPN؛ پیش‌فرض ۳۰ ثانیه |
| `--connection-timeout SEC` | مهلت انتظار وضعیت اتصال/قطع؛ پیش‌فرض ۶۰ ثانیه |
| `--speedtest-timeout SEC` | مهلت هر تست سرعت؛ پیش‌فرض ۱۸۰ ثانیه |
| `--disconnect-existing` | اجازهٔ قطع اتصال قبلی، بدون بازیابی آن |
| `--accept-license` | پذیرش صریح شرایط Ookla و GDPR |
| `--demo` | اجرای آفلاین با اعداد ساختگی |

مهلت فرمان اتصال/قطع و مهلت انتظار تغییر وضعیت، جدا از هم هستند.
کد خروج: `0` موفق، `1` خطا یا نتیجهٔ ناقص، `2` آرگومان نامعتبر و `130` وقفهٔ کاربر.
جزئیات کامل ساختار خروجی در [راهنمای انگلیسی](README.md#reports) آمده است.

```bash
python -m pip install -e '.[dev]'
```

برای تست، بررسی کد و ساخت بستهٔ پایتونی در مخزن قرار دارد.
